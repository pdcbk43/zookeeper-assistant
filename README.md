## 这软件到底解决了什么问题

ZooKeeper Assistant 是 Redisant 出品的一款原生 GUI 工具，支持 Windows、macOS、Linux 三平台。开发商也做了 Redis Assistant、Kafka Assistant 这些同系列产品，在中间件管理工具这个圈子里算是有一定口碑的。

核心功能说白了就几个方向：

**可视化节点管理**：树状结构展示所有节点，多标签页同时开几个连接，在开发/测试/生产环境之间切来切去不用来回重连。标签页这个设计挺实用的，毕竟现在项目稍微大一点，同时开着好几个 ZK 集群的情况不少见。

**实时状态仪表盘**：软件内置仪表盘，能看到每秒流入流出字节、延迟、排队请求数这些健康指标，不用去翻日志猜状态。运维同学对这个会比较感兴趣。

**数据格式化**：这个说真的是刚需。ZK 节点里塞的内容什么格式都有，JSON、XML、MessagePack、Gzip，软件会自动识别并格式化显示。再也不用手动去解析那一坨了。

**多样化搜索**：支持正则、整词、大小写匹配搜索节点，海量节点环境下找数据不用一层一层翻。

**命令行支持**：zkCli.sh 提供的命令和四字符命令都支持，喜欢敲命令的人也不会觉得受限。

**GPU 渲染**：利用 GPU 来渲染界面，启动快，滚动和操作流畅度都不错，内存占用控制得也还行。
